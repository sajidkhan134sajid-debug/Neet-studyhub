# Free launch + earning setup

NEET StudyHub is designed to let students enter for ₹0 while leaving room for legitimate revenue:

- Approved display ads/sponsor placements
- Optional Plus subscription
- Original or properly licensed notes/tests/resources
- Verified mentor/educator rooms
- Legitimate affiliate/partner links

The current build does **not** pretend that an ad network has approved the site and does **not** collect real payments. Connect those providers only after creating and verifying the relevant accounts.
